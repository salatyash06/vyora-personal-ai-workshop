# VYORA

Your voice. Your workspace. Your assistant.

A desktop-first frontend for VYORA, a personal Windows AI assistant. The UI is a
frontend only — a separate local Python FastAPI service owns audio capture,
transcription, speech output, the AI model, and the SQLite database.

## Local backend connection

- The assistant service is expected at `http://127.0.0.1:8000`.
- This frontend runs on **port 8080** in development (`http://localhost:8080`),
  which is one of the origins the backend already allows (localhost and
  127.0.0.1 on ports 5173 and 8080). No backend CORS change is needed.
- On first load, enter the connection token generated by the local service. It is
  validated with `GET /api/status` before being stored, kept in `sessionStorage`
  only, and sent as `Authorization: Bearer <token>` on every `/api` request.
- Tokens are never hardcoded, never placed in a URL, and never read from build
  variables.

## Local mode vs demo mode

- Opened from `localhost` or `127.0.0.1` → real integration with the local
  FastAPI service.
- Opened from any other address, including the hosted preview → clearly labelled
  **DEMO MODE** with simulated sample data, because a hosted page cannot reach a
  service running on your own computer.

## Development

```sh
npm i
npm run dev
```

Then open `http://localhost:8080` with the Python service running.
